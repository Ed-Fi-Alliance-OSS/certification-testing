# Certification Artifact (SIS and MTSS)

The certification scenarios artifact (`certification-<version>.zip`; `sis-<version>.zip` up to v2.1.0) is intended to be used by `Ed-Fi Admin App`, `Ed-Fi Representatives`, and `Ed-Fi Vendors`.

## What is included

- `SIS/` — Bruno collection with the SIS certification scenarios.
- `MTSS/` — Bruno collection with the Intervention (MTSS) v5 certification scenarios (see `MTSS/README.md`).
- `package.json` and `package-lock.json` — dependency manifest.
- `scripts/`, `schemas/`, `templates/` — supporting runtime files.
- `README-User-Manual.md` — Bruno UI setup and execution guide.
- `README-Artifact-How-to-use-in-Bruno-CLI.md` — Bruno CLI setup and execution guide.
- `README-Artifact-How-to-use-in-AdminApp.md` — Admin App setup and execution guide.
